# Character Library

Cada personagem recorrente deve possuir uma pasta própria antes de entrar em produção recorrente.

## Estrutura recomendada
`characters/<character-name>/`
- `profile.md` — identidade, função narrativa, idade aparente e descrição geral.
- `visual-rules.md` — rosto, cabelo, roupa, proporções, expressões e elementos imutáveis.
- `personality.md` — motivações, comportamento, limites e forma de reagir.
- `prompts.md` — prompts visuais e narrativos aprovados.
- `continuity.md` — fatos canônicos e mudanças aprovadas.

## Regra
Nenhum personagem recorrente deve mudar visual ou personalidade silenciosamente. Toda mudança relevante precisa ser documentada e versionada.
