# Visual Bible

Versão: 0.1

## Objetivo
Definir uma linguagem visual consistente para Shorts e vídeos longos, mesmo quando diferentes ferramentas de IA forem usadas.

## Direção inicial
- Cinematográfico.
- Visualmente simples.
- Alto contraste entre sujeito e fundo.
- Um foco principal por cena.
- Perspectiva, escala e iluminação usadas para criar impacto.
- Evitar aparência de stock image ou render genérico.

## Shorts
- Formato vertical 9:16.
- Primeiro frame precisa funcionar como hook visual.
- Mudanças visuais frequentes sem virar ruído.
- Cada cena deve mover a história adiante.
- Texto na tela deve ser curto e legível.

## Vídeos longos
- 16:9.
- Visual deve alternar entre explicação, tensão e recompensa.
- Thumbnails não devem depender de detalhes pequenos.

## Personagens
- Aparência recorrente deve seguir Character Bible específica.
- Não mudar rosto, idade aparente, cabelo, proporções ou roupa principal sem decisão documentada.
- Expressões devem reforçar a narrativa.

## Interfaces, telas e mensagens
Decisão 2026-10-03 (`docs/proposals/2026-10-03-file-001-continuity.md` D6):
- Não imitar alertas de emergência reais, telas de emergência do iOS, alertas de emergência do Android ou qualquer sistema governamental.
- Não reproduzir interfaces reconhecíveis de sistemas operacionais, apps ou emissoras reais.
- Mensagens anômalas usam uma **interface fictícia própria** (anomaly-message interface).
- Especificação: `docs/visual/anomaly-message-interface.md` (v1.0, aguardando aprovação do owner antes da etapa `assets` do FILE #001).
- Overlays editoriais do arquivo (ex.: `FILE #001 — ARCHIVED`) devem ser visualmente distintos da interface dentro do universo.

## Câmera
Preferências iniciais:
- close para emoção;
- wide para escala;
- low angle para ameaça;
- top-down quando ajudar a explicar;
- movimentos simples e legíveis.

## Iluminação
- Usar luz como elemento narrativo.
- Mistério: contraste, sombras e fontes direcionais.
- Ciência/What If: iluminação limpa ou cinematográfica conforme o cenário.
- Evitar cenas excessivamente escuras em mobile.

## Consistência
Quando um estilo visual demonstrar performance superior, registrar em `analytics/learnings.md` antes de promovê-lo a padrão definitivo.
