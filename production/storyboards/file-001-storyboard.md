## Canonical scene list
This file is the **source of truth for scene count**. Each `## scene-NN` heading is one scene. The pipeline derives the scene count from these headings. Each component uses a shot ID (`scene-NN-shot-MM`) and a take ID. Raw clips use `output/file-001/clips/scene-NN-shot-MM-take-TT.mp4`; assembled scene renders may use `scene-NN.mp4`. The asset record (`episodes/file-001/assets.json`) distinguishes them. See `docs/file-001-handoff.md` for the shot list and acceptance contracts.
## Global continuity
- **Moon:** full Moon, same phase and surface detail in every shot. Normal size until scene-06.
- **Time:** one instant, 03:17:00 UTC. Locations are generic (no landmarks, flags, real brands or readable real-world signage):
  - Night location (UTC−4): local 23:17, Moon visible.
  - Morning location (UTC+5): local 08:17, daylight, full Moon below the horizon.
  - Midday location (UTC+9): local 12:17, bright daylight.
- **Phone screens:** every screen uses the fictional interface in `docs/visual/anomaly-message-interface.md`. Screen content is a **composited 2D layer**, never generated by the video model (generated text is unreliable and may drift toward real OS UI).
- **Phones:** generic slab phones with no visible logos or OS chrome.
- **Characters:** anonymous one-off people, no recurring characters (no Archivist). The *window man* (scenes 03, 04, 06, 07) and the *ground woman* (scene 07) must stay consistent within this episode only.
- **Look:** cinematic, high contrast, one focal point per frame, readable on mobile; avoid overly dark frames.
