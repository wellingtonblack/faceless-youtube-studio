# Prompt Library

Biblioteca de prompts aprovados e reutilizáveis.

## Categorias
- `scripts.md` — roteiros e variações narrativas.
- `images.md` — imagens, personagens, cenários e consistência visual.
- `video.md` — animação e geração de vídeo.
- `thumbnails.md` — conceitos e prompts para thumbnails.
- `titles.md` — geração e avaliação de títulos.

## Regra
Prompts só devem ser promovidos a padrão quando produzirem resultados consistentes. Toda mudança que afete identidade deve respeitar `MASTER_RULES.md`, `docs/brand-bible.md`, `docs/visual-bible.md` e Character Bible aplicável.
